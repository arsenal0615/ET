# HTML 原型验证

## 概述

将策划需求文档转化为一个直观的单文件 HTML 原型。核心目的是向策划清晰展示对需求的理解，并确认所有功能点均已覆盖。

**开始时宣告：** "正在使用 qx-prototype 创建 HTML 原型。"

## 执行流程

1. **解析需求**：深度解析需求文档，提取所有目标功能点
2. **构建原型**：按以下要求开发 HTML 原型
3. **保存文件**：保存到与策划文档同一目录
4. **反馈用户**：提供生成的 HTML 文件路径

## 原型开发要求

### 功能全覆盖
- 提取所有功能对应的 HTML UI 组件（操作按钮、表单输入、数据表格、状态标签、导航菜单等）
- 绝不能遗漏任何一个策划要求的功能点

### 结构与布局
- 使用现代化的内联 CSS 样式（Flexbox/Grid）
- 界面结构清晰、主次分明
- 重点在于逻辑和功能的表达，确保策划能一眼看懂功能布局

### 交互与状态示意
- 使用简易的内联 JavaScript 模拟核心交互逻辑
- 点击按钮弹出确认框、切换不同状态视图、展开/折叠面板等
- 以动态形式展现操作流程

### 规则说明与占位
- 对于无法直接通过 UI 表现的复杂后台逻辑、数值计算规则或未定内容
- 在界面对应的组件旁添加醒目的文本说明、角标或悬浮提示（Tooltip）进行解释

### 开箱即用
- 所有 HTML、CSS 和 JS 代码整合在一个文件中
- 不依赖任何外部本地资源
- 双击即可在浏览器中完美预览

## 输出

- 保存 HTML 文件到策划文档同一目录，命名为 `[系统名称]-prototype.html`
- 向用户提供文件路径
