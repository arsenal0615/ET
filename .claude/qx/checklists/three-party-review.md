# 开三方评审检查清单

> 用于 qx-three-party-review Skill 流程追踪。

## 评审前

- [ ] 待评审文档已完成并保存为文件
- [ ] 确定文档类型（GDD / 技术提案 / UX设计 / Sprint计划）
- [ ] 选定 3 个评审角色及其审查视角

## 评审中

- [ ] 3 个评审角色已并行分派
- [ ] 每个评审包含：优点、关注点（分级）、问题、结论
- [ ] 关注点已分级：Critical / Important / Suggestion
- [ ] 评审引用了文档具体章节

## 评审后

- [ ] 合成评审报告已生成
- [ ] 共识结论已确定（APPROVE / APPROVE WITH CONDITIONS / REQUEST CHANGES）
- [ ] Critical 问题已列出（如有）
- [ ] 意见冲突已记录（如有）
- [ ] 评审记录已保存到 docs/reviews/
- [ ] 下一步行动已明确
