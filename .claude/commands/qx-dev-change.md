---

Invoke the `qx-dev-change` skill.

Subcommand and arguments: $ARGUMENTS

Supported subcommands:
- `create <name>` — Create a new change
- `propose` — Write/edit change proposal
- `spec` — Define requirements and specs
- `design` — Write technical design
- `verify` — Verify implementation completeness
- `archive` — Archive completed change
- `status` — Show current change status
- `list` — List all active changes
