Invoke the `qx-gd-sprint` skill.

Determine mode from arguments:
- `plan` or no args → Sprint Planning mode
- `status` → Sprint Status mode
- `retro` → Sprint Retrospective mode (same as `/qx-retro`)

Arguments: $ARGUMENTS
