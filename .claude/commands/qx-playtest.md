Create a playtesting plan for the game or specific feature.

## Process

1. Define playtest objectives (what are we trying to learn?)
2. Determine playtest type:
   - **Internal**: Team members, focused on mechanics/systems
   - **External**: Target audience, focused on experience/accessibility
3. Design the session:
   - Duration and scope
   - Tasks for testers
   - Observation checklist
   - Feedback questions
4. Define success metrics
5. Save to: `docs/test-plans/playtest-{name}.md`
