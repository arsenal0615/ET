Create a Product Requirements Document (PRD) using the QX PRD template.

## Process

1. Read PRD template from `.claude/qx/templates/prd-template.md`
2. Collaborate with user to fill in each section:
   - Product overview and objectives
   - Target users and personas
   - Functional requirements
   - Non-functional requirements
   - User stories with acceptance criteria
   - Success metrics
   - Timeline and milestones
3. Save to: `docs/game-design/prd-{name}.md`
