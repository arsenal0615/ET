Invoke the `qx-exec` skill to execute an implementation plan.

Usage:
- `/qx-exec docs/changes/feature/plan.md` — Execute plan
- `/qx-exec --loop docs/changes/feature/plan.md` — Execute with persistent loop

Plan path and options: $ARGUMENTS
