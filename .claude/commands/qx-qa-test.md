Invoke the `qx-qa-test` skill for test planning and execution.

Mode:
- `design` or no args → Create test scenarios and test plan
- `automate` → Generate automated test scripts from existing test plan
- `execute` → Run tests, collect results, report

Arguments: $ARGUMENTS
