Invoke the `qx-dev-exec` skill to execute an implementation plan.

Usage:
- `/qx-dev-exec docs/changes/feature/plan.md` — Execute plan
- `/qx-dev-exec --loop docs/changes/feature/plan.md` — Execute with persistent loop

Plan path and options: $ARGUMENTS
